# Employee Management System

A simple full-stack Employee Management System built using **Spring Boot**, **Thymeleaf**, **MySQL**, and **Docker**.

## Features

- View employee list
- Add new employee
- Edit employee details
- Delete employee
- Form validation
- MySQL database integration
- Docker support

## Tech Stack

- Java 17
- Spring Boot
- Spring MVC
- Spring Data JPA
- Thymeleaf
- MySQL
- Docker
- Maven
- HTML/CSS/Bootstrap
